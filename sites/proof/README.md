# Proof site

An introduction to generating and independently verifying evidence from git history.

[Site](https://kairevicius.github.io/skills/proof/) · [Skill](../../skills/proof/SKILL.md)

## Build and check

Run from the repository root:

```bash
export SKILL_ROOT="$PWD/skills/proof"
(cd "$SKILL_ROOT/scripts" && npm ci && npm test)
node sites/optical-balance/build-docs.mjs
node sites/build-docs.mjs
node scripts/site-smoke.mjs
```

The optical build needs its own `npm ci` first. The proof page is generated by `../build-docs.mjs` using the shared layout and canonical install block.
Only the skill folder installs; this site's sources stay in the repository.

## Evaluation fixtures

`evals.json` contains prompts and checkable expectations. Build the fixture repositories with:

```bash
node "$SKILL_ROOT/scripts/make-fixture-repo.mjs" \
  --out /tmp/proof-fixture --design-out /tmp/proof-design-fixture
```

Add `--bare-out /tmp/proof-bare` for evaluations that fetch a remote over `file://`.
