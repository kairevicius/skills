Choose a skill

Each skill has one job, a repeatable workflow, and scripts that check its output.

  • Optical balance ↗Center and size logos and icons by what the eye sees. Get the CSS offset and check the rendered result.
  • Proof ↗Turn one person's git history into claims backed by commits and files. Re-derive a received proof before trusting it.

Install

Use the skills CLI. It asks which skills and agents to install for.

npx skills@latest add kairevicius/skills

Add -a <agent> to choose agents, such as -a codex -a cursor. Add -g for a user install.

Without the CLI, copy a folder from skills/ into your agent's skills folder. Follow its SKILL.md for setup.

Use it

Ask your agent to run a skill against your actual asset or repository.

Use optical-balance to center this logo in its tile.
Use proof to turn my work in this repository into evidence.
